# C benchmarks

This folder contains C implementations of the benchmark set and C-specific automation.

## Contents

- Benchmark folders: `fannkuch-redux`, `fasta`, `mandelbrot`, `n-body`, `reverse-complement`
- `compile_all.py`: runs benchmark actions by scanning `Makefile`s
- CSV outputs (`C.csv`, `xC.csv`, `output.csv`): historical/generated measurement summaries

## Notes

- Source files are benchmark-game variants (for example `*.gcc-*.c`).
- JSON files in benchmark folders are measurement exports and should be kept for reproducibility.
- `output.csv` is generated by measurement runs; it is kept because it is part of historical experiment records.
